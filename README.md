# TeachHub

**TeachHub** is an educational web platform built with React + TypeScript + Vite. It connects teachers and students in a seamless way, providing tools for communication, course management, reports, and interactive learning.

Live Demo: https://aljafarawy-teach-hub.vercel.app/

---

## Features

- Organized dashboard showing key sections like Courses, Assignments, Reports, and Top Students.
- Detailed profile pages for teachers and students.
- Blog page for sharing educational posts and announcements.
- Contact page for user support and communication.
- About page introducing the platform’s mission and vision.
- Clean and responsive design with Tailwind CSS.
- Fast performance with Vite + React.

## Technologies

- **React + TypeScript** – for building interactive and type-safe interfaces.
- **Tailwind CSS** – for fast and modern UI design.
- **Vite** – for blazing-fast development and build.
- **React Router** – for navigation and routing.
- **Cloudinary** – for image hosting and management.
- **Vercel** – for deployment and hosting.
